# YouTube Ad Skipper - Chrome Extension

## 📌 Description
This Chrome extension automatically skips YouTube ads by clicking the "Skip Ad" button when it appears. It also removes banner ads from videos.

## 🚀 Features
- ✅ Automatically clicks the "Skip Ad" button.
- ✅ Removes overlay/banner ads.
- ✅ Works in the background without user intervention.
- ✅ Lightweight and fast.

## 🔧 Installation
1. Download or clone the repository.
2. Open Chrome and go to `chrome://extensions/`.
3. Enable "Developer mode" (top right corner).
4. Click "Load unpacked" and select the project folder.
5. Enjoy ad-free YouTube!

## 🛠 How It Works
- The `content.js` script continuously checks for ads and clicks the "Skip Ad" button when available.
- The `background.js` ensures the script is loaded whenever a YouTube video page is opened.

# YouTube Reklam Atlayıcı - Chrome Uzantısı

## 📌 Açıklama
Bu Chrome uzantısı, YouTube'daki "Reklamı Atla" butonuna otomatik olarak tıklayarak reklamları atlar. Ayrıca video üzerindeki banner reklamları kaldırır.

## 🚀 Özellikler
- ✅ "Reklamı Atla" butonuna otomatik tıklar.
- ✅ Video üzerindeki banner reklamları kaldırır.
- ✅ Arka planda çalışır, kullanıcı müdahalesi gerektirmez.
- ✅ Hafif ve hızlıdır.

## 🔧 Kurulum
1. Depoyu indirin veya klonlayın.
2. Chrome'u açın ve `chrome://extensions/` adresine gidin.
3. Sağ üst köşeden "Geliştirici Modu"nu etkinleştirin.
4. "Paketlenmemiş yükle" butonuna tıklayın ve proje klasörünü seçin.
5. Reklamsız YouTube'un tadını çıkarın! 🎉

## 🛠 Çalışma Mantığı
- `content.js` dosyası, YouTube sayfasını sürekli tarar ve "Reklamı Atla" butonuna tıklar.
- `background.js`, YouTube video sayfası açıldığında `content.js` dosyasını çalıştırır.
